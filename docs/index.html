Method

DeepSeek proposes LF class concepts and a dataset-independent broad perceptual vocabulary. CLAP grounding, activation filtering, and projectability filtering determine which concepts are retained. The concept bottleneck is followed by a sparse linear classifier.

Temporal explanations use 1.0 s windows with a 0.5 s hop and follow plot_temporal_concept_explanations.py. The LLM proposes candidates; it does not decide whether a concept is present in the audio.
